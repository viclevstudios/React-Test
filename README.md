# React Fullstack Playground
This is a practice repository for me to learn Fullstack Development with React in the frontend and Express.js in the backend. 
I started this repo when following the React course by [SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev) and then started building my own small projects for practice. 

## The repository includes: 
### Projects from the React Course:
- react basics: fundamental react features (part of SuperSimpleDevs tutorial)
- chatbot project: a simple chatbot in React that gives predefined answers to questions (part of SuperSimpleDevs tutorial)
- ecommerce project: the frontend of a simple ecommerce store (part of SuperSimpleDevs tutorial)
- ecommerce project ts: the same ecommerce project, but used to learn typescript (part of SuperSimpleDevs tutorial)

### Weather App:
A simple weather app using Open-Meteos API
Features: 
- Search for locations and saving them
- Display general weather data for saved locations
- Show detailed information for saved locations

A project that started as a simple frontend-only todo list app.
Currently though, I'm using this project to learn backend development (Express.js, PostgreSQL, JWT-Auth, etc.)
Features: 
- Display, create, edit and delete todos
- Save the todos into a Postgres database through an Express.js backend
- Currently in progress: Authentication and Authorization with JWT
